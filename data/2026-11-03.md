### [1] [Explain, Then Forget: Recommendation Unlearning under Asymmetric Access Constraint](https://arxiv.org/abs/2610.40658)
*Haichao Zhang, Chong Zhang, Wen Wang, Shi Qiu, Peiyu Hu, Jia Wang*

Main category: cs.IR | Domain: 推荐系统/Recommender System | Importance: 中/Medium

TL;DR: 提出CEU（Causal Explanation-based Unlearning），在MLaaS架构下不改模型参数，通过"因果贡献估计 + 输出层打分干预"两步实现推荐去学习。

Ranking Relevance: 与排序链路中的重排/后处理环节直接相关：CEU把去学习落到最终打分干预上，属于"排序分后校正"范式，可与多样性、业务规则干预、校准层共置于同一重排模块；工业价值在于黑盒/托管模型（第三方排序API、跨团队模型服务）下的合规遗忘与噪声样本纠偏，无需重训即低延迟上线。局限：因果贡献估计精度决定遗忘与效用的权衡，且仅作用于被曝光物品，对召回/预排层的传播影响无覆盖；缺乏参数层面可证明的遗忘保证，难以满足严格监管审计要求。

<details>
  <summary>Details</summary>
Motivation: 推荐系统需遗忘噪声点击/过期偏好等历史交互，但MLaaS下模型由模型提供方托管、服务运营方仅能通过API访问，无法触碰内部参数，重训练/微调类去学习方法失效。

Method: 两步输出级分数干预：(1) 用因果解释方法估计被遗忘交互对当前推荐的因果贡献；(2) 依据该因果信号调整受影响物品的最终排序分数以消除其影响。不改权重，天然支持连续多次去学习请求，避免重复参数更新带来的误差累积。

Result: 在三个公开数据集上，去学习效果与全量重训练相当，同时保持推荐效用并显著降低计算开销。

Conclusion: 输出层干预式去学习可作为MLaaS场景下可行的隐私/合规遗忘方案，但本质是后处理校正而非真正移除参数中的信息，存在被后续查询近似复原、分布漂移下失效的隐患。

Abstract: Recommendation unlearning aims to remove the influence of specific historical interactions that should no longer affect future recommendations, such as noisy clicks or outdated user preferences. However, performing recommendation unlearning becomes much harder in modern Machine-Learning-as-a-Service (MLaaS) architectures, where the recommendation model is remotely hosted by a model provider (MP) and accessed by service operators (SO) only through APIs. In this setting, a service operator serves end users but cannot access or modify internal model parameters. As a result, existing unlearning methods are difficult to apply because they require access to model internals for retraining, fine-tuning, or other parameter updates. To address these challenges, we propose Causal Explanation-based Unlearning (CEU), a novel unlearning framework tailored for MLaaS environments. Instead of modifying internal model weights, CEU operates through a two-step output-level score intervention. First, it estimates how the forgotten interaction causally contributes to the current recommendation. Second, guided by this causal signal, the system removes the influence of the forgotten interaction by adjusting the final ranking scores of affected items. Because CEU leaves model parameters untouched, it naturally supports continuous unlearning requests while avoiding the error accumulation that can result from repeated parameter updates. Extensive experiments on three public datasets show that CEU achieves unlearning effectiveness comparable to full retraining while preserving recommendation utility and significantly reducing computational cost. The source code is available at: https://github.com/zhang-haichao/Explain-and-Forget.

### [2] [Retrieve-then-Disambiguate: Scalable Reviewer Discovery](https://arxiv.org/abs/2610.40768)

Our code is available at https://github.com/deepthought-initiative/Retrieve-then-Disambiguate.

<details>
  <summary>Details</summary>

Conclusion: 可复现静态测试集是公平比较聚焦爬虫的必要基础设施；语义嵌入式链接价值评估优于传统文本/关键词方案；数据集、代码与模型已公开。

Since it can only fetch a limited number of pages, its success depends on choosing which links to follow. Any crawler can be run on exactly the same sites and scored against the same labels. The collection, codebase, and models are publicly released to support experimental replication and fair crawler comparison.
