### [1] [Assessing the Downstream Utility of Evidence-Aware Retrieval in RAG](https://arxiv.org/abs/2608.26379)
*Utshab Kumar Ghosh, Debayan Mukhopadhyay, Shubham Chatterjee*

Main category: cs.IR | Domain: 搜索引擎/其他 | Importance: 中

TL;DR: 本文系统研究RAG检索评估从"主题相关性"转向"答案证据支持性"后，这种对齐是否真的能让下游决策更可靠。通过5个检索基准和TREC RAG 2025端到端设置，作者在四个角色中检验答案支持信号：比较检索器、指导检索训练与系统选择、预测下游答案质量、过滤提供给生成器的证据。结论是：该信号虽能改变检索排名，但下游价值并不统一——不总能改善检索训练，系统选择收益取决于生成器如何使用证据，检索分数无法稳健预测未见过主题的答案质量。研究表明，让检索评估更贴合生成所需证据，并不能自动让所有下游用途更可靠。

Ranking Relevance: 论文的核心是检索评估信号（答案支持度）在检索系统中的多种下游用途。这与排序模型密切相关：检索排序打分本身就是一个排序问题，答案支持信号可被视作一种新的相关性标签或排序目标。对于工业推荐/搜索系统，这篇论文的重要启示在于"评估指标与下游目标的对齐不等于指标在所有下游任务中都有用"——这对工业界中常见的"以某个代理指标优化排序模型"的做法有警示意义。虽然论文聚焦RAG场景而非传统CTR/CVR排序，但其关于评估信号在不同决策场景下价值非均匀的发现，对排序模型的离线评估指标设计、在线系统选择、训练目标制定都有直接参考价值。

Motivation: RAG系统的检索评估正从主题相关性转向"是否包含支持生成的证据"，但这种转变是否真正提升了检索评估在各类下游决策（比较检索器、训练、系统选择、答案质量预测、证据过滤）中的实用价值，目前缺乏系统性的实证检验。作者希望回答：更强的证据对齐是否必然带来更可靠的决策支持。

Result: 答案支持信号确实改变了检索排名，但影响不均匀：不能可靠改善检索器训练；用于系统选择时收益取决于生成器的指令方式；基于该信号的检索分数在未见过主题上无法稳健预测答案质量。在直接证据干预中，人类标注确认过滤确实优先保留含有效答案证据的段落，但不同答案评估器对生成答案是否改善得出了不同结论。

Abstract: Retrieval evaluation for retrieval-augmented generation (RAG) is increasingly designed around whether retrieved passages contain evidence that can support generation, rather than topical relevance alone. We study whether this closer alignment with downstream evidence needs also makes retrieval evaluation more useful for the decisions built from it.

The signal changes retrieval rankings, but its downstream value is not uniform. It does not reliably improve retriever training; the benefit of using it for system selection depends on how the generator is instructed to use the retrieved evidence; and retrieval scores based on it do not robustly predict answer quality on unseen topics. In a direct evidence intervention, human annotators confirm that filtering preferentially preserves passages containing useful answer evidence, yet different answer evaluators reach different conclusions about whether the resulting answers improve.

RAG evaluation methods should therefore be assessed with respect to the particular comparisons, decisions, and conclusions they are intended to support.

Extensive experiments and a human preference study show that proFILL outperforms diverse RAG baselines, is preferred by target users, and remains effective with open-weight models for cost-effective on-premise deployment.

The construction generalizes the NAPP index from a constant number of pivots to a linear-size vocabulary, which keeps posting lists at constant expected length $ρ= k_b/α$ as $n$ grows and turns the index into a combinator: any high-recall index on $αn$ points yields an index on $n$ points, for any metric.
