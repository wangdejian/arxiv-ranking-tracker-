### [1] [Algebraic Retrieval: Composable Search for Agents](https://arxiv.org/abs/2609.19482)
*Damian Delmas*

Main category: cs.IR | Domain: 召回模型/Recall | Importance: 低

TL;DR: 提出「代数检索」（Algebraic Retrieval），让 AI Agent 在查询时把相关性标准、资格约束与排序偏好统一表达为数学查询，并在 PEM（Programmatic Embedding Modulation）基础上验证对比打分、候选池重排、加权排序等可组合查询，与 SQL、PyTerrier 实现做执行一致性对比。

Ranking Relevance: 与排序模型关联较弱。亮点在于把「排序偏好」显式纳入查询表达式并支持候选池重排与加权排序，属于排序逻辑的可组合化/可编程化思路，对 Agent 驱动的检索编排有一定启发；但本文只验证执行一致性（集合与分数一致），不涉及排序建模、特征交互或效果指标（NDCG/CTR 等），也未在工业级数据规模与延迟约束下评估，对主流 LTR/CTR 排序模型研究影响有限。

<details>
  <summary>Details</summary>
Motivation: 现有检索系统把相关性判断、过滤约束、排序偏好分散在不同模块（查询语言、过滤器、排序器）中，Agent 难以在查询时灵活组合与修订策略。作者希望提供一个暴露可用算子（向量算术、分数算术）的统一查询表面，使 Agent 能针对具体问题现场组合操作、检查结果后再改写程序。

Method: 在 Programmatic Embedding Modulation（PEM）之上，暴露向量与分数的算术操作，将对比打分（contrastive scoring）、候选池重排、加权排序统一表达为可组合的数学查询；同时给出等价的 SQL 与 PyTerrier 实现作为对照，在公开的 Vaswani 数据集（11,429 篇文档）上评测各实现的执行一致性。

Result: 在 Vaswani 固定测试集上，各程序实现选出的文档集合完全一致，分数差异低于 1e-6；仅存在一对并列文档在不同打分路径下排序不同。论文明确说明其评估目标是执行一致性（execution parity），而非 Agent 行为或检索质量。

Conclusion: 代数检索为 Agent 提供了可组合、可修订的检索查询抽象，并初步验证了其与 SQL/PyTerrier 在文档选择与分数上的执行等价性。但工作仍停留在「执行正确性」层面，未证明检索质量、Agent 决策收益或工业级规模下的性能，距离工业落地尚有较大距离。

Abstract: Algebraic Retrieval lets AI agents compose search strategies at query time. Relevance criteria, eligibility constraints, and ranking preferences can be expressed together in a mathematical query. The query surface exposes available operations, so an agent can combine them for the question at hand and revise a program after inspecting results. We evaluate execution parity, not agent behavior or retrieval quality. Building on Programmatic Embedding Modulation (PEM), which exposes vector and score arithmetic during retrieval, we demonstrate contrastive scoring, candidate-pool reranking, and weighted ranking as composable queries, alongside executable SQL and PyTerrier counterparts. On the public 11,429-document Vaswani fixture, each program's implementations select the same document set with score differences below 1e-6; one tied pair orders differently across scoring paths.

### [2] [Beyond Similarity through Zero-Token Geometric Graphs for Multi-Hop RAG](https://arxiv.org/abs/2609.19622)
*Zeliang Li, Xiaofen Xing, Kailing Guo, Xiangmin Xu*

Main category: cs.IR | Domain: 召回模型/Recall | Importance: 中

TL;DR: G³RAG：一种无需LLM的文档级图构建多跳RAG框架，通过几何增益分数(cosθ·sinθ)构建图边并结合密度感知拓扑惩罚与单步受控扩散，在多跳QA数据集上取得最优F1与命中率。

Ranking Relevance: 该工作属多跳检索/召回阶段技术，与排序模型的关联为间接但值得关注：(1) 其"几何增益分数 cosθ·sinθ"本质上是一个无参、可离线预计算的边权打分函数，思路可迁移到召回/粗排阶段的互补性建模与多样性控制，类似MMR但更具几何可解释性；(2) 密度感知拓扑惩罚抑制hub节点，与推荐中流行度去偏(popularity debiasing)、图神经网络邻居采样中的度归一化同源，可用于改善召回结果的覆盖与去中心化；(3) 单步受控扩散可作为多路召回融合与证据聚合的候选生成器，输出的文档集合与相关性信号可喂给下游精排模型，或将扩散步数/增益分数作为排序特征。对工业系统而言，其最大价值在于以极低的计算与存储开销（无LLM token成本）实现多跳召回，适合作为召回通道补充或RAG检索器替换方案。

<details>
  <summary>Details</summary>
Motivation: 多跳RAG需要既相关又能桥接语义鸿沟的新证据。稠密检索易集中于语义相似文档，而图方法依赖昂贵的LLM实体抽取且易沿噪声连接传播。作者希望在无LLM参与图构建的前提下，用文档表示的几何结构支撑高效多跳证据发现。

Method: 1) 离线图构建仅用文档，无LLM调用或生成token；2) 每条边赋予几何增益分数 cosθ·sinθ，同时刻画方向一致性与正交性（互补性）；3) 密度感知拓扑惩罚抑制高连接度hub节点；4) 从过滤后的查询种子出发，进行单步受控扩散以检索互补证据。

Result: 在MusiQue、2WikiMultiHopQA、HotpotQA上，使用Nv-embed-v2和Qwen3-8B-embed两种嵌入设置，平均F1与答案文档命中率均优于所评估的图基线，平均提升最高4.26 F1，MusiQue上达5.76分，并消除了实体图方法的图构建token成本。

Conclusion: 几何结构可支撑高效多跳证据发现，且无需基于LLM的图构建，为多跳检索提供了低成本、可落地的替代方案。

Abstract: Multi-hop retrieval-augmented generation (RAG) requires evidence that remains relevant to a query while introducing enough novelty to bridge semantic gaps. Dense retrieval tends to concentrate on semantically similar documents, whereas graph-based alternatives often depend on costly Large Language Model (LLM) entity extraction and may propagate through noisy connections. G$^3$RAG assigns each edge a geometric gain score, $\cosθ\cdot \sinθ$, that jointly captures directional consistency and orthogonality between document representations. A density-aware topological penalty suppresses highly connected hubs, while single-step controlled diffusion expands from filtered query seeds toward complementary evidence. We evaluate G$^3$RAG on MusiQue, 2WikiMultiHopQA, and HotpotQA using Nv-embed-v2 and Qwen3-8B-embed. G$^3$RAG obtains the best average F1 and answer-document hit rate among the evaluated graph-based baselines in both embedding settings, with gains of up to 4.26 F1 points in average performance and 5.76 points on MusiQue. It also removes the graph-construction token cost incurred by entity-based graph methods. These results show that geometric structure can support efficient multi-hop evidence discovery without LLM-based graph construction. Code is available at https://anonymous.4open.science/r/G3RAG-99D9/

Ranking Relevance: 本文位于排序之前的召回/索引环节：索引键质量决定候选集上限，直接影响后续精排可用空间。其"自动诊断-修正-验证"闭环与 A/B 验证思路，可迁移至召回通道的表示与倒排/向量索引治理；Query Simulator 的查询分布外探索，对训练样本构造与冷启动召回有借鉴意义。若与向量检索结合，可与 embedding 微调、索引重训流程联动，成为端到端搜推广链路中"召回端自动化运维"的一环，但对排序模型本身的结构创新贡献有限。

<details>
  <summary>Details</summary>
Motivation: LLM Agent 面临复杂多样的信息需求，检索质量高度依赖索引键对文档知识的表达能力；但最优索引表示随检索环境变化，固定优化策略难以通用。当前索引演化仍依赖人工诊断失败、人工调整优化策略、人工重处理索引，成本高且难以规模化。

Abstract: Information retrieval is increasingly important as LLM agents tackle complex tasks involving diverse information needs. Yet evolving an index to its retrieval environment remains largely human-driven, requiring humans to diagnose retrieval failures, refine the optimization strategy, and reprocess the index accordingly. We propose SELF-INDEX, a framework that enables an index to self-evolve without human intervention. Beyond reacting to observed retrieval demands, SELF-INDEX proactively explores additional demands through a Query Simulator, allowing the index to evolve beyond the queries already available for optimization. Across diverse corpora and retrievers, SELF-INDEX consistently improves retrieval performance while outperforming existing index optimization methods. We further show that these benefits extend to downstream applications, improving the effectiveness and efficiency of search agents and helping agent memory systems retrieve useful past interactions.
