### [1] [SAGE: Semantic Attribute Graphs for Multi-Entity Visual Retrieval](https://arxiv.org/abs/2609.04255)
*Yongjoo Kim, Mincheol Kwon, Seonga Choi, Minseung Lee, Kyeong-Jin Oh, Hyunyoung Lee, Yunsu Choi, Jungbeom Lee*

Main category: cs.IR | Domain: 向量检索/Vector Retrieval | Importance: 中/Medium

TL;DR: 本文提出SAGE框架，解决稠密文档图像中细粒度实体检索时的"语义稀释"问题。SAGE无需训练，通过解析文档图像中的语义实体、将其表示为层级图节点并采用多向量嵌入，再通过迭代的实体级子图匹配来检索与查询相关的证据。同时引入DEAR数据集（1,055对query-image），来自产品详情页，涵盖四种递增复杂度的查询类型。

Ranking Relevance: 本文属于视觉-语言检索方向，与传统搜推广系统中的排序模型并非直接同域，但关联性体现在以下几点：(1) 核心问题"语义稀释"本质上是一个表征质量问题——单向量编码将多实体信息压缩，这与推荐/搜索中item侧多头特征被压缩为单一embedding导致的细粒度语义丢失问题高度相似，可类比到工业排序模型中多兴趣/多头embedding的表示学习设计；(2) 多向量嵌入和层级图结构可以作为排序模型中特征交互或表征层设计的参考；(3) 子图匹配式检索的思路可迁移至推荐召回或精排阶段的"多粒度/多兴趣匹配"场景，尤其在电商商品详情页、文档类内容推荐的query-文档细粒度匹配中有应用潜力。不过该工作偏重检索而非排序本身的损失函数或特征交互架构，因此对排序模型的直接方法论贡献有限。

  <summary>Details</summary>
Motivation: 标准视觉-语言检索器用单向量编码裁剪区域，在稠密文档图像中会将多个不同实体的信号混合在一起，导致细粒度实体级检索时证据模糊。作者将这一失效模式命名为"语义稀释"（Semantic Dilution），并定量证明了实体密度越高，实体级检索质量退化越严重。

Method: SAGE是一个无需训练的框架，核心流程为：(1) 从稠密文档图像中解析语义实体；(2) 将实体建模为层级图结构节点，每个节点采用多向量嵌入（multi-vector embeddings）来表示；(3) 通过迭代的实体级子图匹配来检索与查询相关的证据，避免单向量编码导致的信号混合问题。

Result: 在DEAR数据集上，SAGE显著缓解了语义稀释问题，优于patch级和OCR-based的检索基线。在多实体视觉比较查询上Recall@3达到0.849，生成分数为2.746。

Conclusion: 多向量层级图表示比单向量区域编码更能捕捉稠密文档中的细粒度实体信号，训练无关的图匹配式检索框架可在文档检索场景有效对抗语义稀释，为视觉密集文档的实体级检索提供了一条可行路径。

Abstract: Dense document images often contain many fine-grained visual and textual entities whose relevance depends on a user query. Standard vision-language retrievers encode cropped regions with a single vector, which can mix distinct entity signals and obscure the evidence needed for fine-grained retrieval. We call this failure mode Semantic Dilution and quantitatively show that it degrades entity-level retrieval as a function of entity density. To mitigate it, we propose SAGE, a training-free framework that parses semantic entities from dense document images, represents them as hierarchical graph nodes with multi-vector embeddings, and retrieves query-relevant evidence through iterative entity-level subgraph matching. We also introduce DEAR, a dataset of 1,055 query--image pairs sourced from product detail pages, where each query requires retrieving and comparing multiple fine-grained entities from visually dense inputs across four question types of increasing complexity. Experiments show that SAGE substantially reduces semantic dilution and outperforms patch-level and OCR-based retrieval baselines on DEAR, achieving a Recall@3 of 0.849 and a generation score of 2.746 on multi-entity visual comparison queries. Our code is available at https://github.com/All4Nothing/SAGE.

To address semantic fragility, an Uncertainty-Aware Fusion module models the aleatoric uncertainty of heterogeneous modalities, dynamically down-weighting unreliable features while prioritizing high-confidence signals as a defense against cross-modal noise.
