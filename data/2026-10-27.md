### [1] [PinGER: Token-Efficient Generative Retrieval with Semantic IDs](https://arxiv.org/abs/2610.33435)
*Xinyi Li, Sujan Reddy Ale, Yi-Ping Hsu, Zelun Wang, Yilin Chen, Hanyu Li, Hanlin Lu, Arkin Dharawat, Lulu Yao, Yaxin Li, Bella Huang, Xiangyi Chen, Jaewon Yang, Jiajing Xu, Charles Rosenberg*

Main category: cs.IR | Domain: 召回模型/Recall | Importance: 高/High

TL;DR: PinGER 是 Pinterest 落地的生成式召回器：训练时用非对称注意力掩码让"交错 SID+稠密向量"序列中的后续 item 只关注稠密 token，从而在训练时监督每个 SID 位置、服务时每 item 只需 1 个 token，压缩上下文长度约 L 倍；配合目标条件生成+RL+前缀多样性惩罚实现可控、多样化生成，以及面向宽 beam 的高效服务栈（合法 ID 约束解码+本地索引解析）。线上 Related Pins 场景新 Pin 收藏 +3.60%、整体收藏 +0.62%，端到端延迟 -0.7%，并省去 ANN 检索成本。

Ranking Relevance: 该工作位于召回层，但其"训练时全监督、服务时压缩输入"的掩码设计和可控生成（goal-conditioned + RL + 多样性）对排序/重排同样有借鉴价值：一是长用户行为序列的上下文压缩（与 SIM/长序列建模、token 压缩路线相通）；二是用 RL 直接优化业务目标与多样性约束，可迁移到重排的序列生成式建模范式（generative reranking）；三是其宽 beam 约束解码与服务栈设计为生成式模型在工业级高 QPS 召回链路落地提供了成本与延迟的可行性证据，说明生成式召回已具备替代双塔+ANN 的工程条件。

Motivation: 生成式召回（TIGER 类）用语义 ID（SID）逐 token 解码替代 ANN 检索，但用户历史若每个 item 用 L 个 SID token 序列表示，则固定上下文窗口能容纳的 item 数缩小为 1/L，长序列建模与实时性受限；同时缺少对多目标/多样性的可控生成与服务端效率方案。

Method: 三点核心：(1) 非对称注意力掩码：输入序列交错 SID token 与单个稠密 embedding token，后续 item 的 SID 位置只能关注稠密 token 而非前序 SID，保证训练时每个 SID 位置都有监督信号，推理时只喂一个稠密 token 即计算同一函数，等价于"训练长、服务短"的上下文压缩；(2) 可控生成：goal-conditioned 输出 + 强化学习 + prefix-diversity 惩罚，引导检索朝向特定场景目标并提升候选多样性；(3) 工程：为宽 beam 生成优化的服务栈、约束解码到合法标识符空间、host-local 索引做候选解析，替代原有最近邻检索。

Result: Pinterest Related Pins 线上：新 Pin 收藏数 +3.60%，整体收藏 +0.62%，该场景端到端延迟 -0.7%，同时消除被替代的 ANN 检索成本。

Conclusion: SID 生成式召回可以在不牺牲输出形式的前提下把输入侧压缩为稠密向量，从而恢复上下文容量；训练-服务的掩码对称性设计是其关键；目标条件+RL+多样性惩罚是实现多目标可控召回的可复制范式；宽 beam 约束解码+本地索引是实现低延迟、低成本的工程必备。

Abstract: Generative retrieval replaces nearest-neighbor search with token-by-token decoding of an item's semantic ID (SID). But existing SID-based methods primarily use L levels of tokens sequentially to represent each item in the input history. As a result, a fixed context window holds L times fewer items than it would with one embedding per item. We present PinGER, a generative retriever deployed at Pinterest that retains SID outputs while making input histories compact, built on three ideas. (1) An asymmetric attention mask over interleaved SID and dense tokens lets later items attend only to the dense ones, so the model is supervised at every SID position in training yet serves one token per item while computing the same function. (2) Generation is controllable through goal-conditioned outputs, reinforcement learning, and a prefix-diversity penalty, which together steer retrieval toward surface-specific goals and diverse candidates. (3) A serving stack built for efficient wide-beam generation is paired with decoding constrained to valid identifiers and candidate resolution from a host-local index. Deployed in Related Pins, PinGER lifts saves of fresh Pins by 3.60% and overall saves by 0.62%, while reducing the surface's end-to-end latency by 0.7% and eliminating the cost of the nearest-neighbor search it replaces.
